## 🐛 How to Report Bugs

If you encounter a bug or crash while using RAMGuard Pro:

1. Check existing issues on [GitHub Issues](https://github.com/jojin1709/ramguard-pro/issues) to avoid duplicates.
2. Open a new issue using the **Bug Report** template.
3. Provide details:
   - Your Windows OS version (e.g. Windows 11 23H2).
   - Expected behavior vs actual behavior.
   - Steps to reproduce the issue.
