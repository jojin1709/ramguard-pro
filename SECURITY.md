---

## Reporting a Vulnerability

Security and stability are critical priorities for **RAMGuard Pro**. If you discover a security vulnerability or critical issue:

1. **Do NOT open a public GitHub issue** for undisclosed security vulnerabilities.
2. Report the vulnerability directly to **JOJIN JOHN**:
   - **Developer**: JOJIN JOHN
   - **GitHub Profile**: [https://github.com/jojin1709](https://github.com/jojin1709)
   - **Private Security Disclosure**: [https://github.com/jojin1709/ramguard-pro/security/advisories/new](https://github.com/jojin1709/ramguard-pro/security/advisories/new)

Please include:
- A description of the vulnerability and potential impact.
- Step-by-step instructions or proof-of-concept to reproduce the issue.
- Operating system version (e.g., Windows 10/11 x64).

### Response Timeline
- **Acknowledgement**: Within 48 hours.
- **Assessment & Fix**: Security patches will be released in an updated `.exe` release as soon as verified.

## Security Best Practices for Users
- Always run official executables downloaded directly from [https://github.com/jojin1709/ramguard-pro/releases](https://github.com/jojin1709/ramguard-pro/releases).
- Verify UAC Administrator prompt details when launching RAMGuard Pro.
